# Dependencies for the photo -> 3D mesh -> Blender turntable pipeline.
#
# torch/torchvision are deliberately NOT listed. They must match your CUDA build
# and are already installed here as 2.13.0+cu130 / 0.28.0+cu130 (Blackwell sm_120).
# Installing them via a bare `torch` requirement — as Hunyuan3D-2's own
# requirements.txt does — can silently replace a working CUDA build with a CPU one.
# If you need them on a fresh machine, pick the right index explicitly, e.g.:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130
#
# Blender is NOT a pip dependency either: `pip install bpy` requires Python 3.13
# and this venv is 3.10. Run ./setup_blender.sh instead.

# rembg >= 2.0.70 requires Python >= 3.11, so pin for 3.10.
